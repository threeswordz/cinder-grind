# 2. Release Objective

V0.2 extends the accepted V0.1 Foundation with Project scheduling and site-execution capabilities while preserving the canonical architecture:

**Project → WBS → Activity**

Scheduling data and calculations remain backend/domain-owned and independent of the Gantt visualization component.

# 6. Architecture and Governance Constraints

V0.2 preserves:

- modular monolith
- PostgreSQL + Prisma
- REST API
- backend-enforced permissions
- database-derived Project scope
- System Administrator/business-authority separation
- WBS and Cost Code independence
- `Activity` as the canonical technical/database/API term
- Frappe Gantt as a replaceable visualization component only
- DEC-008 open-source / zero-cost-first runtime constraint
- no mandatory paid cloud/runtime/service dependency

---

# 7. Release Boundary

V0.2 includes only requirements whose Target Release is **V0.2 Project & Scheduling** in the approved Requirements Baseline.

V0.3 Procurement, BOQ/Budget, Inventory, Subcontracts, Finance, Cost Control and Management functionality remains outside V0.2 unless a future approved Change Request changes the baseline.

# 9. Exit Boundary

V0.2 is not complete until:

- all V0.2 Must Have requirements meet their approved acceptance criteria

- applicable frontend workflows are complete
- permissions, Project scope, validation and audit controls pass
- automated critical/regression/security tests pass
- Staging/UAT validation passes
- Severity 1 defects = 0
- unresolved Severity 2 defects are resolved or formally accepted
- deployment/rollback documentation is current
- Product / Business Owner release acceptance is recorded
