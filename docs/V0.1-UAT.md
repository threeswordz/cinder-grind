# Construction ERP — V0.1 UAT Record

**Release:** V0.1 Foundation  
**UAT scenario:** UAT-V01-FOUNDATION-001  
**Business process:** Foundation setup → Project → WBS / Cost Code → Project Document → access control

## 1. Purpose

This record is the manual business acceptance companion to the automated V0.1 test suite. Automated tests establish technical correctness. UAT confirms that the V0.1 Foundation is usable and correct for the approved business process. Development/CI cannot provide Product / Business Owner sign-off.

## 2. Entry criteria

- [ ] release scope and acceptance criteria are approved
- [ ] release candidate is deployed to the Staging/UAT environment
- [ ] all source-controlled migrations are applied
- [ ] automated critical/regression tests are green
- [ ] Staging/UAT smoke test passes
- [ ] blocking technical defects are resolved
- [ ] dedicated UAT data exists
- [ ] UAT users have the intended Roles/Permissions

## 3. Test data

Prepare:

- active Customer: Factory Customer
- active Employee linked to Project Manager User
- active Material: Reinforcement Steel
- active UOM: Each
- configurable active Project Status
- active Document Type suitable for a contract/project file
- second active project-scoped User/Employee not assigned to PJ26001
- safe sample PDF/document for upload

Do not use sensitive real-world credentials or confidential files for UAT evidence.
