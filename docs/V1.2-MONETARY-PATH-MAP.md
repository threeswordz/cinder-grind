## Supported historical neutralization

These are narrow existing operations, not exceptions for new procurement or settlement:

- Direct Cost: negative exact `reversesPostingId`, original currency/dimensions, reason, original approval and existing maker/checker/idempotency/concurrency controls.
- Project Variation: exact `reversesVariationId` / original denomination, reason and existing approval/permission controls.
- Subcontract Certification: existing approved → REVERSED operation; paired retention reversal inherits the exact original withholding identity/amount/currency. No invented withholding if historical evidence is absent.
- Subcontract Variation: existing approved → REVERSED operation under its protected-ceiling and source controls.
- Existing cancellation/rejection/withdrawal and inventory source-linked compensations retain their existing restrictions and cannot edit commercial values or introduce foreign settlement.
- Exact create/action retries return the persisted historical record before new-activity validation; changed payloads remain conflicts. Replay metadata does not create economic activity.
