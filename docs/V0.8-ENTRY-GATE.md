## 3. Approved architecture boundary

V0.8 Management is a read-only / derived management and reporting layer over canonical source modules.

It does not create:

- a second editable KPI source-of-truth ledger;
- a duplicate financial ledger;
- a duplicate schedule engine;
- a duplicate procurement risk engine;
- synthetic missing-value allocation;
- unapproved FX or mixed-currency conversion.

Canonical source ownership remains with Project/Scheduling/Site, Procurement, Inventory, Subcontracts, Finance and Cost Control.

4. **V0.8-D — Domain Dashboards: Schedule / Procurement / Inventory / Cost / Finance**
5. **V0.8-E — Cross-Module Reporting / Export / Hardening / Release Evidence**

## 5. Approved explicit deferrals

The approved initial V0.8 baseline excludes unless separately approved through Change Control:

- predictive / ML forecasting and AI-generated management decisions;
- separate editable management KPI ledger;
- synthetic Project/WBS/Cost Code allocation;
- data warehouse / OLAP / ETL platform;
- persistent daily KPI snapshot warehouse;
- tax/VAT/statutory accounting;
- GL/journals/chart of accounts/accrual accounting;
- FX conversion / mixed-currency consolidation;
- unapproved inventory valuation;
- automated Equipment Cost Allocation without a canonical costing rule;
- mandatory paid BI/reporting services;
- scheduled email/report distribution;
- arbitrary end-user report builder/query language;
- advanced PDF/XLSX report designer.

## 6. Governance and security
