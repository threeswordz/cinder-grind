## Bounded C3 runtime scope

C3 adds source-owned navigation only among existing authorized source modules:

- Project → WBS / Activities.
- Project / WBS context → BOQ & Budget first-approved Original Budget and approved revision history.
- Project context → Site Execution evidence.
- Project / dimensional context → Cost Control.
- Permission-scoped source drilldowns into Management dashboards and reports.

## Non-regression boundaries

- Original Budget remains the first approved baseline; C3 must not rewrite, recalculate or relabel historical originals.
- WBS and Cost Code dimensions remain independent and source-owned.
- Empty, unknown or unauthorized Project/record targets fail closed and must not leave stale source detail selected.
- Existing Management backend permission/Company/Project filtering remains authoritative.
- Authorized Executive Portfolio viewers retain approved cross-Project budget/cost/revenue/profit/cash totals after backend scope filtering.
- C3 must not fabricate unsupported source drilldowns or forbid authorized portfolio aggregation.
- Existing Project, Scheduling, Budget, Site Execution, Cost Control and Management mutation/approval semantics are unchanged.
