## Scope

Stage A implements the read-only Cost Control integration layer approved under DEC-024:

- Original Budget and Revised Budget from canonical V0.3 Budget Revisions;
- Procurement Committed Cost from the latest applicable approved PO revision;
- Subcontract Committed Cost from the approved active Agreement value plus approved non-reversed subcontract Variations; approved Work Orders allocate portions of that ceiling to their canonical WBS / Cost Code dimensions without adding commitment, and any uncovered ceiling remains Unallocated;
- Supplier Actual Cost from final-approved Supplier Invoice items;
- Subcontract Actual Cost from approved non-reversed gross Certification;
- Paid Cost from approved non-cancelled OUTBOUND Finance allocations to eligible cost targets;
- Project / WBS / Cost Code filtering with parent-WBS descendant rollup;
- explicit Unallocated / Partially Allocated / Fully Allocated dimensional states instead of synthetic proration;
- sanitized source evidence under `cost.control.view` and detailed record evidence only when matching source-module view permissions are also held.

## API

`GET /api/v1/projects/{projectId}/cost-control`

Optional query filters:

- `wbsId` — selected WBS plus descendants;
- `costCodeId` — exact independent Company Cost Code.

## Security

- explicit `cost.control.view` is mandatory;
- Company isolation and effective database-derived Project access remain mandatory;
- `projects.access_all` does not grant Cost Control authority;
- SYS_ADMIN has no implicit Cost Control authority;
- detailed source records are hidden unless source-module view permission is also present.

## Financial authority

- PostgreSQL / Prisma Decimal remains authoritative;
- mixed/non-base-currency eligible sources return an explicit unsupported-currency error;
- no JavaScript floating-point calculation determines financial truth.

## Explicit Stage-A exclusions

- Direct Cost Posting;
- Forecast / ETC / Cost to Complete / Variance;
- client Project Variations;
- revenue / profit;
- Inventory valuation / Goods Receipt Actual Cost;
- mutation endpoints;
- synthetic dimensional proration.
