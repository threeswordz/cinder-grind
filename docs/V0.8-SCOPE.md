## 1. Purpose

V0.8 Management consolidates approved source-module information into management dashboards and cross-module reporting without creating a second source of truth.

Management surfaces are **read-only derived views** over canonical Project, Scheduling/Site, Procurement, Inventory, Subcontracts, Finance and Cost Control data.

## 3. Canonical source ownership

- **Project / Scheduling / Site:** owns Projects, WBS, Activities, baseline/current dates, progress, critical path, lookahead, Daily Site Reports, site issues and delay evidence.
- **Procurement:** owns PR/RFQ/Quotation/PO state and Required-on-Site versus Expected Delivery schedule-risk evidence.
- **Inventory:** owns stock balances and movements.
- **Subcontracts:** owns subcontract commitments, claims, certifications, retention and subcontract variations.
- **Finance:** owns Supplier/Client Invoices, AP/AR, Payments, allocations and Project Cash Flow.
- **Cost Control:** owns approved integrated Budget/Committed/Actual/Paid/Forecast/Variance and Project commercial/revenue/profit measures.
- **V0.8 Management:** owns no duplicate editable business transaction or financial ledger. It only composes authorized read models, dashboard preferences if later approved, and export presentation.

## 4. Approved explicit exclusions / deferrals

Unless separately approved through Change Control, V0.8 excludes:

- predictive/ML forecasting or AI-generated management decisions;
- a separate management KPI source-of-truth ledger;
- editable dashboard values that override canonical source data;
- synthetic allocation/proration of missing Project/WBS/Cost Code values;
- historical data warehouse / OLAP cube / ETL platform;
- persistent daily KPI snapshot warehouse;
- tax/VAT/statutory reporting;
- GL/journals/chart of accounts/accrual accounting;
- FX conversion or mixed-currency consolidation;
- inventory valuation not already approved in source modules;
- automated Equipment Cost Allocation without an approved canonical equipment costing rule;
- custom BI server or mandatory paid analytics/reporting platform;
- scheduled email/report distribution;
- arbitrary end-user report-builder/query language;
- advanced PDF/XLSX designer; initial export baseline is controlled CSV and browser-printable views where appropriate.
