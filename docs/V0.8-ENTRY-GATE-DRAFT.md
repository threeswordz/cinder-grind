## Proposed architecture

Management is a **derived read/composition layer**.

It consumes canonical source-module data and approved reporting services. It does not create a second editable operational/financial source of truth.

## Proposed stage sequence

1. V0.8-A — Management Read Model / KPI Contracts
2. V0.8-B — Project Engineer & Project Manager Dashboards
3. V0.8-C — Executive / Cross-Project Management Dashboard
