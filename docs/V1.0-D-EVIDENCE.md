## AC-V10-027 — Health / readiness

- `/api/v1/health/live` is dependency-free process liveness.
- `/api/v1/health/ready` checks PostgreSQL and required Documents storage.
- `/api/v1/health` remains a compatibility readiness alias.
- Production Documents readiness reuses the existing deployment-specific sentinel and verifies read/write accessibility.
- Health payloads remain non-sensitive.

## AC-V10-028 — Server-controlled correlation

- every request receives a server-generated UUID;
- inbound `X-Correlation-ID` is no longer authoritative;
- response/problem details retain the server correlation ID.

## AC-V10-029 — Structured operational logging

- machine-readable JSON message bodies for request completion, login outcome, startup/failure and unhandled server errors;
- migration start/complete events are emitted by the Production preparation path;
- request paths are sanitized to exclude query strings;
- credentials, tokens, request bodies, database URLs and raw storage paths are not logged.

## AC-V10-030 — Retention / rotation

`docs/OPERATIONS-RUNBOOK.md` defines bounded provider-neutral retention using native/open-source host/container facilities. The application does not create an unbounded log file.

## AC-V10-031 — Operations runbook

`docs/OPERATIONS-RUNBOOK.md` consolidates health/readiness interpretation, correlation/log lookup, startup/restart, deployment failure, backup/recovery references and initial incident triage without replacing the canonical V1.0-A/B procedures.

## AC-V10-032 — Performance / capacity evidence

`apps/api/scripts/v1-0-d-benchmark.mjs` is bounded to confirmed non-Production use and is executed by CI against the isolated live-acceptance fixture. It records readiness, authenticated read and safe session-mutation latency/throughput observations.

Final exact-head run numbers and JSON observations will be copied into `docs/V1.0-D-PERFORMANCE-EVIDENCE.md` after stable-candidate CI.

## AC-V10-033 — Concurrency / idempotency regression

`docs/V1.0-D-CONCURRENCY-EVIDENCE.md` maps the delivered approval, Finance, Inventory and Subcontract contention/idempotency protections. A release-level test asserts that those canonical suites remain in the API regression command; normal CI executes them against isolated PostgreSQL.

## AC-V10-034 — Open-source / zero-cost observability

No runtime dependency was added. Logging uses Nest/Node stdout/stderr, health/readiness is application-local, benchmark tooling uses Node built-ins and retention guidance uses native/open-source facilities.
