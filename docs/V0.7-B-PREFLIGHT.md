## Scope and requirement trace

Stage B implements the Direct Cost portion of COST-004/COST-013 and RPT-009 under D07-07–10, BR-V07-01/03/04/11–16 and applicable AC-V07-010/020–023/026–043/045–050. It reuses the completed Stage-A source read model and existing approval/audit/authorization frameworks.

- Cost Control-owned Direct Cost Posting is only for costs not already represented by AP/Subcontracts.
- Project and Cost Code are required; WBS is optional and belongs to that Project. WBS and Cost Code remain independent.
- Configured approval with maker-checker; retained submission/approval/rejection evidence.
- Approved postings are immutable. Corrections use linked reversal and retained history.
- Only final-approved postings contribute Direct Actual Cost on posting date.
- Direct Actual Cost does not automatically create Paid Cost, a Payment, Project Cash Flow or a duplicate AP/Subcontract transaction.
- Decimal server/database arithmetic preserves source precision and retained base currency; mismatched/unknown provenance never becomes FX or numeric reinterpretation.
