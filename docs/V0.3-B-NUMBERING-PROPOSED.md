# Construction ERP — V0.3-B Proposed Business Numbering

**Status:** APPROVED  
**Decision source:** BR-V03-17  
**Applies before:** V0.3-B Purchase Request implementation

## Proposed baseline

| Document | Template | Reset | Example |
| --- | --- | --- | --- |
| Budget Revision | `BRYY-###` | YEARLY | `BR26-001` |
| Purchase Request | `PRYYMM-###` | MONTHLY | `PR2604-001` |
| Request for Quotation | `RFQYYMM-###` | MONTHLY | `RFQ2604-001` |
| Purchase Order | `POYYMM-###` | MONTHLY | `PO2604-001` |

## Approved-rule alignment

The proposal preserves BR-V03-17:

- each document type has its own Company-scoped sequence
- the number is assigned when the transaction/revision is created
- the number never changes
- rejected/cancelled numbers are never reused
- reset periods remain globally distinguishable because YY or YYMM is embedded in the visible number
- UI, API and exports use the same immutable business number
- the existing Number Sequence engine already supports `YY`, `MM`, one `#` group, and NONE/YEARLY/MONTHLY reset rules

## Scope effect

Approval of this document authorizes the numbering convention only. It does not approve or implement RFQ or PO functionality early.

V0.3-B implementation remains limited to PROC-001 through PROC-003 plus the already-approved PR business rules.
