Stage A may implement only:

1. Company-scoped Warehouse persistence and migration.
2. unique user-assigned Warehouse code.
3. name, location, optional Project, site flag and active/archive lifecycle.
4. same-Company Project integrity and immutable ownership/history rules.
5. Warehouse/Inventory foundation permissions and audit.
6. scoped Warehouse REST APIs and responsive Warehouse UI.
7. approved Inventory numbering foundation through the existing Company sequence abstraction.
8. unit, PostgreSQL integration, authorization, live HTTP and regression coverage.
9. API/ERD/permissions/current-state documentation.

Goods Receipt, stock posting, balance, reservation, issue, return, transfer, Inventory Documents/reporting, valuation and Finance remain excluded.
