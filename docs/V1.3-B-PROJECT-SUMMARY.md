## Project-only contract

`GET /budget/summary/projects`, `GET /budget/summary/projects/:id` and `/export` require current persisted `budget.project_summary.view`, active Company/user and database-derived Project scope. A forward-only migration adds this one catalog definition; it grants no role or user access. Full cost, customer-price, Finance source permissions and technical role names do not implicitly grant it. Combining it with Quantity Only permits exactly those two explicit views.

The response contains minimal Project identity, recorded currency and exactly three decimal-string totals. No dates/WBS/Cost Code/line filters are accepted, including on CSV; no invoice/payment/Customer BOQ/source-line IDs, descriptions, quantities, prices, allocation amounts, costs, markup, margins or attachments are returned.

| Field | Canonical source and recognition |
|---|---|
| `contractAmount` | Project contract value plus active approved original Project Variations; an approved linked compensating reversal removes the original. Reuses existing exact sum/reversal functions. |
| `billedAmount` | Final-approved Client Invoice header totals in this Company/Project. Draft/submitted/rejected records and other Projects are excluded. |
| `receivedAmount` | Approved, non-cancelled INBOUND Payment amounts in this Company/Project, including unallocated receipts. OUTBOUND Payments are excluded. This is received cash, not Paid Cost, allocated invoice settlement or receivables balance. |

Reads use one repeatable-read transaction for authority, membership and source snapshot consistency. Known zero totals return `0.00`; missing Project currency, mismatched Company currency or mismatched included source currencies fail closed. There is no denomination inference, conversion, relabelling, omission of mismatched included rows or stored-data correction. Existing historical sources remain unchanged. No BOQ/Finance ledger or audit write is created by summary reads.

CSV contains the same Project fields and three totals, with exact two-place values and formula-safe labels. Print refetches the authorized summary; changed Project/unmounted contexts suppress late print/download. A failed fresh read/action hides the previous totals and removes its printable snapshot; Refresh can recover without resurrecting a denied cached view. The existing authenticated root replaces caches on user/Company/permission/role changes. EN/Thai/Traditional Chinese explain the source semantics. Authorized totals plus independently known quantities may permit price inference; no complete inference-prevention claim is made. Summary actors without explicit full revision read cannot use Budget-bearing alternate reports/Forecast. Unclassified old Project/WBS uploads remain withheld without both full cost reads; classified Finance documents remain independently available with their source authority. Two failing-before isolated regressions exposed the missing new-capability integration, then passed after extending the existing guards.
