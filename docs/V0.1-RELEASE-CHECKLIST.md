# Construction ERP — V0.1 Release Checklist

**Release:** V0.1 Foundation  
**Stage:** V0.1-H Integration / Regression / UAT  
**Source of truth:** GitHub Issue #27, PR #28, CI and approved V0.1 baselines

## 1. Release scope

V0.1 Foundation includes the technical platform, Company / Identity / Security, Administration, Master Data, Projects, WBS & Cost Codes, Basic Project Documents, and release integration/UAT.

V0.1 does not require V0.2+ Activities, scheduling, Gantt, site execution, BOQ/Budget, Procurement, Inventory, Subcontracts, Finance or Cost Control.

## 4. V0.1 reference acceptance flow

1. Administrator configures an active Project Manager User and permissions.
2. Customer, Employee, Material and UOM exist.
3. Project Manager signs in.
4. Project Manager creates Project PJ26001.
5. Project references the Customer.
6. Project Team contains the linked Employee.
7. Project Manager creates 01 Groundworks and 01.01 Ground Floor Slab.
8. Authorized user creates independent Cost Code MAT-STEEL.
9. Project Manager uploads a Project document.
10. Assigned Project user can view the Project/document.
11. Unassigned project-scoped user cannot access them.
12. Audit evidence exists for applicable actions.
13. Logout revokes the authenticated session.

## 5. Security release gate

Release is blocked by unauthorized protected API access, Project-scope bypass, implicit business approval by System Administrator, editable audit history, secret leakage, missing CSRF on applicable mutations, document path traversal, physical storage-path exposure, committed secrets, or sensitive infrastructure/database error leakage.

## 6. Known V0.1 boundaries

- single-company prototype application scope
- local filesystem is the prototype document storage provider
- Project Documents only; WBS/Activity document links are later scope
- Project Actual Start / Actual Completion are V0.2
- Activities / scheduling / Gantt are V0.2
- no offline synchronization
- no SSO / SCIM
- no multi-currency accounting
- no Production hosting provider is mandated by the V0.1 architecture
