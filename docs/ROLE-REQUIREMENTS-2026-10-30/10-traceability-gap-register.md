## Classification

- **implemented:** cited implementation/test or accepted release evidence supports the principal requirement, with limits retained.
- **configuration-only:** a reusable mechanism exists; named role/workflow activation requires configuration evidence and, later, separately authorized change.
- **partially implemented:** related functionality exists but misses a stated rule/handoff/data field.
- **missing:** complete reviewed model plus relevant route/service surface lacks the requested domain workflow. This is a bounded source conclusion, not proof about an unseen deployment.
- **unverified:** available evidence is insufficient, or the policy itself remains unanswered. Unknown is not failure.

Runtime configuration is a separate column. Code/test evidence never proves actual named-user grants. Existing CI success is observed evidence; no database/business/UI tests were executed by this assessment.
